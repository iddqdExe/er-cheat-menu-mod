# ER Cheat Menu Mod

Проект внутриигрового меню Elden Ring для локального тестирования сборок.

Планируемые возможности: выдача предметов и рун, редактирование характеристик, открытие карты и мест благодати, сохранение наборов для повторных тестов. Интерфейс предполагает каталог с игровыми иконками, поиск, фильтры и понятную группировку действий.

## Состояние

Подготовлен [проект устройства и оформления мода](docs/superpowers/specs/2026-10-12-er-multitool-design.md) для согласования. Реализация и проверка внутри игры ещё не начаты. Готовой DLL для установки пока нет.

Локально обнаружена Elden Ring с версией исполняемого файла `2.7.1.0` и установленным загрузчиком DLL-модов. Совместимость будущего мода ещё предстоит проверить.

## Исходные материалы

Локальная таблица Cheat Engine используется как справочный материал для исследования функций. Она не включается в репозиторий. Игровые архивы, извлечённые изображения и сохранения также не публикуются.

Предполагается использование в офлайн-режиме. Обход античита не входит в проект.
